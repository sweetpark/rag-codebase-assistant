# RAG Codebase Assistant

레거시 **JSP + MyBatis** 코드베이스를 대상으로, 코드에 자동으로 주석/커밋 메시지를 생성하고 이를 학습 데이터로 축적해 **RAG 기반 코드 어시스턴트**를 만들어보는 실험/프로토타입 프로젝트입니다.

> 사내 AI 활용 아이디어 경진대회 출품작을 정리한 저장소로, 실제 운영 배포보다는 **아키텍처 설계와 파서/청킹/재랭킹 파이프라인 실험**에 초점을 맞췄습니다.

## 배경 및 목표

- 오래된 JSP/MyBatis 기반 서비스는 문서화가 부족해 신규 인력의 코드 이해 비용이 큼
- 코드를 청크 단위로 쪼개 LLM으로 주석·설명을 자동 생성하고, 이를 누적해 **사내 코드에 특화된 RAG 어시스턴트**로 발전시키는 것을 목표로 함
- "AST 기반 코드 파싱 → 청킹 → LLM 주석 생성 → 임베딩 저장 → RAG 질의응답"까지 전체 파이프라인을 단계별로 설계/실험

## 프로젝트 구성

| 경로 | 설명 |
|---|---|
| `demo_AI/src` | Spring Boot 데모 애플리케이션 (파서 실험 대상 샘플 코드) |
| `demo_AI/ragPython/chunk.py` | 코드 청킹 스크립트 |
| `demo_AI/reRankPython/python/rerank.py` | 검색 결과 재랭킹(Re-rank) 실험 |
| `demo_AI/pythonFile` | RAG 파이프라인 실험 스크립트 (버전별 반복 실험) |
| `demo_AI/RAG.pptx`, `demo_AI/RAG_PDF.pdf` | RAG 시스템 구축 가이드 발표 자료 |

## 기술 스택

- **파싱**: JavaParser, Jasper(JSP), jsoup(HTML), XML 파서
- **백엔드 샘플**: Spring Boot, MyBatis
- **RAG 파이프라인**: Python (청킹 / 재랭킹 / 임베딩 실험)
- **LLM**: GPT-4 API (주석·커밋 메시지 생성)

### 1단계 — 코드 주석·커밋 메시지 자동화

<pre>
[샘플 API 코드 (JSP/Java + MyBatis XML)]
           │
   (1) 코드 전처리 요청
           ▼
[전처리 서비스]
(AST: JavaParser ← JSP 컴파일러(Jasper) + jsoup + XML 파서)
           │
   (2) 코드 청크 → LLM
           ▼
[LLM 주석/커밋 메시지 서비스]
(파인튜닝된 사내 모델)
           │
   (3) 주석 삽입 & 메시지 제안
           ▼
[Git Hook Runner]
(pre-commit / prepare-commit-msg)
           │
      (4) 개발자 워크스페이스
  → 주석 달린 코드 커밋
  
</pre>
