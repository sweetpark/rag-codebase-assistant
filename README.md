# 1단계
<pre>
[샘플 API 코드 (JSP/Java + MyBatis XML)]
           │
   (1) 코드 전처리 요청
           ▼
[전처리 서비스]
(AST: JavaParser ← JSP 컴파일러(Jasper) + jsoup + XML 파서)
           │
   (2) 코드 청크 → LLM
           ▼
[LLM 주석/커밋 메시지 서비스]
(파인튜닝된 사내 모델)
           │
   (3) 주석 삽입 & 메시지 제안
           ▼
[Git Hook Runner]
(pre-commit / prepare-commit-msg)
           │
      (4) 개발자 워크스페이스
  → 주석 달린 코드 커밋
  
</pre>
